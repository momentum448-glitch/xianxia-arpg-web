# xianxia-arpg-web

Mobile-first portrait browser ARPG with an original xianxia/cultivation setting.

## MVP direction
- Portrait 9:16 mobile browser first
- Real-time top-down combat
- Virtual joystick + auto basic attack + 3 active skills + dodge
- One continuous open-map-lite region
- Male/female player selection
- Cultivation progression with breakthrough moments
- Original 2D/2.5D xianxia art with restrained ink-wash influence

## Stack
Phaser 3 + TypeScript + Vite.

GitHub is the source of truth. The first milestone is a clean playable vertical foundation, not content volume.
